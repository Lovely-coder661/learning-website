# Learning Website

## About the Project
This project is a Learning Website that I created while learning and practicing Git and GitHub. It is a beginner-level project developed to understand the basics of web development and learn how to manage project files using Git.

The main purpose of creating this project was to gain practical experience with Git commands, understand version control, and learn how to upload and manage code on GitHub.

## Project Objectives
- To understand the basics of Git and GitHub.
- To learn how to create and manage repositories.
- To practice adding, modifying, and tracking project files.
- To understand how version control works.
- To gain basic experience in developing a website.
- To improve practical knowledge through hands-on learning.

## Features
- Simple and beginner-friendly website structure.
- Basic web development practice.
- Organized project files and folders.
- Version control using Git.
- Project hosting and code management using GitHub.

## Technologies Used
- **HTML:** Used to create the basic structure of the website.
- **CSS:** Used to style and design the website.
- **JavaScript:** Used to practice adding interactive functionality.
- **Git:** Used to track changes and manage different versions of the project.
- **GitHub:** Used to store and manage the project repository online.

## What I Learned
While working on this project, I learned several important concepts:

1. How to initialize a Git repository using `git init`.
2. How to check the status of files using `git status`.
3. How to add files to the staging area using `git add`.
4. How to save changes using `git commit`.
5. How to connect a local repository with GitHub.
6. How to push project files to a remote repository.
7. How to maintain and organize project files.

## Purpose of This Repository
This repository represents my learning journey as a beginner in web development and version control. It is one of my practice projects created to improve my technical skills and understand how developers manage their projects using Git and GitHub.
